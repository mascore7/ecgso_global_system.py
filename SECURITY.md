## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it privately. **Do not create a public GitHub issue.**

* **Email:** Send details to -email: ecgso36@x@gmail.com
* **Response Time:** You can expect an acknowledgment within 48 hours.

Please include as much detail as possible to help us reproduce and fix the issue quickly.
